# Clean-room origin

Dokki Charts was designed after reviewing public data-visualization tools and Agent Skills, including Lieflat Charts and Microsoft Flint Chart.

Lieflat Charts is distributed under PolyForm Noncommercial 1.0.0. Dokki Charts does not copy or derive its code, HTML templates, tokens, branded visual systems, examples, documentation prose, or assets. The repository implements an independent JSON protocol, SVG renderer, export workflow, accessibility model, theme and examples under MIT-0.

General ideas such as choosing a chart from the data shape, separating quick-reading and exploratory use cases, including provenance, and shipping self-contained HTML are treated as product requirements rather than copied expression.
